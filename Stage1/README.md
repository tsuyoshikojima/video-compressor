# Video Compressor - Stage 1

## 概要

PythonのTCPソケットを使用して作成した、CLI形式のmp4ファイルアップロードシステムです。

クライアントからmp4ファイルをサーバーへ送信し、サーバーは受信したファイルを保存します。

ファイルサイズを事前にサーバーへ通知し、指定されたサイズのデータをすべて受信できた場合のみアップロードを成功として扱います。

## 主な機能

* TCPによるmp4ファイルのアップロード
* CLIからアップロードするファイルを指定
* 1400バイト単位でのファイル送信
* ファイルサイズを利用した受信データ量の管理
* アップロード完了後のステータスレスポンス
* 不完全なアップロードの検出
* 不完全なファイルの削除
* サーバーのストレージ容量制限

## 使用技術

* Python 3
* TCP Socket
* Python Standard Library

外部ライブラリは使用していません。

* TCP接続の待機

* アップロードファイルの保存
* 不完全なアップロードの検出

* レスポンスのエンコード・デコード

## 通信プロトコル

クライアントとサーバー間の通信にはTCPを使用します。

### ファイルアップロード

クライアントは最初に4バイトのヘッダーを送信します。

```text
+------------------------+
| File Size              |
| 4 bytes                |
+------------------------+
| File Data              |
| variable length        |
+------------------------+
```

ファイルサイズは4バイトの符号なし整数として、Big Endian形式で送信します。

```text
File Size: 4 bytes
File Data: file_size bytes
```

その後、クライアントはmp4ファイルを最大1400バイトずつ読み込み、すべてのデータをサーバーへ送信します。

### サーバーレスポンス

アップロード処理後、サーバーは16バイト固定長のレスポンスを返します。

```text
+----------------+-----------------------------+
| Status Code    | Reserved                    |
| 1 byte         | 15 bytes                    |
+----------------+-----------------------------+
```

ステータスコードは以下の通りです。

| Status Code | 意味        |
| ----------- | --------- |
| `0`         | アップロード成功  |
| `1`         | アップロード未完了 |
| `2`         | サーバーエラー   |
| `3`         | サーバーのストレージ不足  |

## アップロード処理

アップロードは以下の流れで行われます。

1. クライアントがmp4ファイルを選択する
2. クライアントがファイルサイズを取得する
3. TCPでサーバーへ接続する
4. 4バイトのファイルサイズヘッダーを送信する
5. ファイルを最大1400バイト単位で送信する
6. サーバーが指定されたファイルサイズまでデータを受信する
7. 完全に受信できた場合のみファイルを保存する
8. サーバーが16バイトのレスポンスを返す
9. クライアントがアップロード結果を表示する

通信途中でクライアントとの接続が切断された場合、不完全なファイルは正常なアップロードとして残しません。

## 実行方法

### 1. サーバーを起動

```bash
python3 server.py
```

サーバーはTCPポート`9001`でクライアントからの接続を待機します。

### 2. 別のターミナルでクライアントを起動

```bash
python3 client.py
```

### 3. mp4ファイルを指定

```text
サーバーにアップロードするmp4ファイルのパスを入力してください。
> /path/to/video.mp4
```

ファイルが存在しない場合や、`.mp4`以外のファイルが指定された場合は再入力を求めます。

アップロードに成功すると、サーバーから返されたステータスに応じて結果が表示されます。

## ストレージ容量制限

サーバーには保存可能なストレージ容量の上限を設定しています。

アップロード開始前に、現在保存されているデータ量と新しくアップロードされるファイルサイズを確認し、容量上限を超える場合はファイルを保存しません。

これにより、サーバーが許可されたストレージ容量を超えてファイルを保存することを防ぎます。

## 動作確認

以下の項目について動作確認を行いました。

* mp4ファイルを正常にアップロードできること
* アップロード元と保存後のファイルサイズが一致すること
* ハッシュ値を比較し、送信前後でファイル内容が一致すること
* `.mp4`以外のファイルをクライアント側で拒否すること
* 存在しないファイルパスを拒否すること
* 通信途中で接続が切断された場合、不完全なファイルを正常なファイルとして保存しないこと
* ストレージ容量上限を超えるアップロードを拒否すること
* アップロード完了後にサーバーからステータスレスポンスが返されること
